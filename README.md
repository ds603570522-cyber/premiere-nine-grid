# 九宫格助手 1.1.1 · 图像序列版

适配目标：Windows Premiere Pro 2025（25.x），本机版本 25.4.0.99。
本地开发测试版：23 组代码／模拟宿主测试通过，尚未完成 PR 内真实图片导入及回放验收。

## 安装／从 1.0 升级
1. 保存工程并退出 PR。
2. 解压整个安装包，双击 `Install.cmd`，无需管理员权限。
3. 重新打开 PR，从“窗口 → 扩展”（或“扩展（旧版）”）打开“九宫格助手”。
4. 面板上方应显示版本 1.1.1。

新版安装器可以直接更新 1.0，会先备份旧插件到 `%LOCALAPPDATA%\Meetavista\NineGridBackups`，保留最初安装时记录的设置。不会自动退出或保存 PR，也不会改动素材文件。

## 图像序列怎么选
1. 素材类型选择“图像序列 · PNG / EXR 等”。
2. 在第 1 格点击“选择首帧”，例如选中 `Camera1.0001.exr`。
3. 确保同一文件夹内还有 `Camera1.0002.exr`、`Camera1.0003.exr` 等。
4. 依次给其余八格选择各自那一组的首帧；九组可以放在不同文件夹。
5. 点两个已填格子可交换位置；“更换首帧”可重新指定该格。
6. 选择输出尺寸、帧率、最小间距，再生成九宫格序列。

每格只需选择一张首帧，PR 会把这组连续图片作为一个运动素材导入。插件检查编号连续性、设置图像序列素材帧率，并核对导入帧数与图片数；不会把九张首帧当作九张静态图直接排版。

支持的首帧选择类型：PNG、EXR、JPG/JPEG、TIF/TIFF、TGA、DPX、BMP；具体像素格式、压缩方式、多层 EXR 支持取决于 PR 导入器。

### 文件命名
- 同组文件需位于同一个文件夹，前缀、扩展名、编号位数一致。
- 编号紧靠扩展名，例如 `Camera1.0001.exr`、`Camera1.0002.exr`。
- 必须从这组最小编号的图片开始，至少两帧，中间不缺号。
- 不满足要求时会提示具体问题并停止生成。

### 帧率、时长和声音
- 图像序列素材帧率与面板所选输出帧率一致：一张图片对应一帧。
- 例如 300 张图片，30 fps 为 10 秒，25 fps 为 12 秒。
- 九格从各自首帧同时开始；最终时长为最短一组，其他组裁切到同样长度。
- 图像序列无内置声音，因此该模式自动静音；背景音乐可以生成后在 PR 中另加。
- 默认 5760 × 3240、30 fps；也支持 4K、1080p 和 24 / 25 / 60 fps。
- 画面等比完整放入每格；画幅不一致时留黑边，最小间距不意味着横竖黑边完全相同。

## 视频文件模式
仍可切换到“视频文件 · MP4 / MOV 等”，一次选择九个视频，按路径自然排序后交换格子。声音可全静音、只保留第 1 格或全部保留。切换素材类型会清空面板本次选择。

## 安装设置与卸载
这是未签名个人插件。安装器按 Adobe 开发文档把当前用户的 `HKCU\Software\Adobe\CSXS.12\PlayerDebugMode` 设为字符串 `1`，允许加载未签名 CEP 12 面板；旧值保存在插件目录的 `install-state.json`。
保存工程并退出 PR，双击 `Uninstall.cmd` 可移除此插件；若开关未被后续改动，会恢复原来的值。其他未签名插件若依赖此开关，恢复后也可能不再显示。升级备份保留在 NineGridBackups 目录。

完整源码位于 `com.meetavista.ninegrid/`，无需 npm。开发测试：`node tests/test.cjs`。
